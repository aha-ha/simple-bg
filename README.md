# Simple BG
### Features:
- A real time clock and date, based on the users system clock
- Seconds and date can be turned off per URL parameter

### URL Parameters
| Name | Type | Default | Explenation |
|------|------|---------|-------------|
|seconds|bool|false|enable/disable seconds display |
|date|bool|true|enable/disable date display|      

### Usage
You can add the URL `https://aha-ha.github.io/simple-bg/?seconds=1&date=1` to your favorite wallpaper app.
